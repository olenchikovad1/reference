# Экраны

Экран берёт элементы из `@platform/ui`. Своей папки компонентов у экрана нет.

| Экран | Что делает |
|---|---|
| `showcase` | Витрина: сетка карточек, фильтры по дропу, адресату, статусу, исполнителю |
| `card` | Карточка референса: изделие, холст слоёв, проверки, замечания, история |
| `tasks` | Мои задачи: на мне / жду других / вернулось с замечаниями |
| `library` | Библиотека элементов, поиск по картинке |
| `products` | Справочник изделий: состояния, печатные поля, размерные сетки |
| `overview` | Обзор к общей встрече: принято, спорно, отклонено, застряло |
| `archive` | Разметка архива: итоги продаж и отметки «повторить» пачками |
