# Свои компоненты — и почему их здесь мало

Набор компонентов и визуальный язык приходят из `@platform/ui` и
`@platform/tokens`. Своего каталога примитивов у приложения нет — это инвариант
платформы И-9, и обходить его нечем: второй набор означает два визуальных языка
в одной оболочке, и расходиться они начинают с первого же экрана.

Эта папка — **названное отступление**, а не лазейка.

## Когда сюда можно класть

Ровно один случай: **в `@platform/ui` такого компонента нет.** У «Референса»
есть свои: холст слоёв, переключатель состояний изделия, ползунок сравнения
версий. Платформа про них не знает и знать не обязана.

## Что отсюда следует

Всё, что лежит здесь, — **кандидат на вынос в `@platform/ui`**. Не «наше
навсегда», а «платформа до этого ещё не дошла». Поэтому:

- компонент пишется так, чтобы его можно было забрать: без знания наших
  доменов, на токенах, а не на своих цветах и отступах;
- прямой импорт Radix и прочих библиотек примитивов законен **только здесь** —
  экраны их не видят. Стережёт `guard_ui_boundary`, раскладка задана в
  `.claude/rails.json`;
- появление третьей папки с компонентами — нарушение, а не вариант.

## Проверка

```bash
py -X utf8 .claude/hooks/guard_ui_boundary.py --scan
```
