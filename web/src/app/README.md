# Монтирование в оболочку

Раскладка берётся из `@platform/shell`. Приложение кладёт свои разделы в область
навигации, содержимое — в область содержимого, и своей шапки не рисует (З-11).

Все ссылки строятся относительно префикса `/reference/`, а не от корня: в
разработке префикс отличается от боевого, и это единственный способ заметить
зашитый корень до выкладки.
