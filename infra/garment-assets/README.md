# garment-assets — сменный том кадров и принтов

Файловое пространство, которое сервис монтирует как `FILES_VOLUME_PATH`
(`/srv/reference/files`). Здесь — кадры состояний изделий и файлы принтов
библиотеки. **Не** исходники `.bw`, **не** нейросети.

Имя нейтральное: том можно заменить другим каталогом (в том числе будущим с
Drive), не меняя код — приложение читает только путь из настройки.

## Наполнение

Из корня репозитория, источник — стенд:

```bash
py scripts/stand/seed_garment_assets.py
```

Другой каталог (prod, внешний диск):

```bash
py scripts/stand/seed_garment_assets.py --dest D:/data/garment-assets
```

## Подключение

В `infra/.env` (или боевом env):

```
FILES_HOST_PATH=./garment-assets
```

На стенде по умолчанию остаётся `./stand/files` (там же модели разметки и
голос). Для проверки «как на prod» — указать этот каталог и пересоздать
сервис `api`.

Нейросети по-прежнему: `py scripts/stand/fetch_models.py` в тот же корень
тома, если на машине нужна разметка.
