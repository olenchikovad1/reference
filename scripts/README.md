# Скрипты

Разбор и замеры данных стенда — только отсюда (CLAUDE.md, запрет 10). Нет
нужного — пишется сюда, в раздел по предмету, и строкой в эту опись.

Где запускается — в шапке каждого скрипта. Коротко: **хост** — одна
стандартная библиотека (плюс PyYAML), `py scripts/<раздел>/<скрипт>.py` из
корня репозитория; **контейнер** — нужны PIL, numpy или код сервиса,
`docker compose -f infra/compose.yaml exec -T api python -m scripts.<раздел>.<скрипт>`.
Том файлов в контейнере только на чтение: что надо записать, уходит в stdout.

## stand — том стенда

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `fetch_models.py` | хост | Нейросети и словарь, без которых стенд собирается, но не работает. До подъёма стенда. |
| `verify_volume.py` | хост | Что в томе на месте, что подменено, чего нет — и откуда взять. Сверяет по хешам из описаний. |

## prints — принты

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `make_probes.py` | хост | Пять эталонов печати: сетка 20 см, линии, буквы, плашка, непрозрачный фон. Детерминирован. |
| `variants.py` | контейнер | Та же картинка, изменённая так, что хеш её не узнаёт: вдвое меньше, JPEG 70, обрезка, светлее, «из чата». |
| `alpha.py` | хост | Вырезан ли принт или это сцена с прозрачной рамкой. |

## garment — изделие

Кадрам и исходнику. Числа в `infra/stand/fixtures/<код>.yaml` сняты этими
скриптами; расхождение с описанием они называют сами.

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `silhouette.py` | хост | Границы силуэта, профиль ширины, место плеч; сетка поверх кадра для чтения координат глазом. |
| `torso.py` | хост | Ширина торса с переда и спины, глубина с бока, низ подола — раздел `torso`. |
| `frame_colour.py` | хост | Обесцвечен ли кадр и гладок ли — годится ли он в карту освещения (решение 0001). |
| `bw_source.py` | хост + zstd | Что внутри исходника VStitcher и как достать файл. zstd: Python 3.14 или `pip install zstandard`. |
| `avatar_scale.py` | хост + zstd | В каких единицах сцена модели — по габариту аватаров против роста в их имени. |
| `geo_mesh_search_failed.py` | хост + zstd | **Не дал результата.** Поиск меша изделия в снимке симуляции — лежит, чтобы не пробовать в третий раз. |

Боковой шов скриптом не мерится: угол 90° принят решением 24.09.2026
(`torso.side_seam_deg`), настоящий берётся из лекала.
