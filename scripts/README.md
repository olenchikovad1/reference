# Скрипты

Разбор и замеры данных стенда — только отсюда (CLAUDE.md, запрет 10). Нет
нужного — пишется сюда, в раздел по предмету, и строкой в эту опись.

Где запускается — в шапке каждого скрипта. Коротко: **хост** — одна
стандартная библиотека (плюс PyYAML), `py scripts/<раздел>/<скрипт>.py` из
корня репозитория; **контейнер** — нужны PIL, numpy или код сервиса,
`docker compose -f infra/compose.yaml exec -T api python -m scripts.<раздел>.<скрипт>`.
Том файлов в контейнере только на чтение: что надо записать, уходит в stdout.

## stand — том стенда

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `fetch_models.py` | хост | Нейросети и словарь, без которых стенд собирается, но не работает. До подъёма стенда. |
| `verify_volume.py` | хост | Что в томе на месте, что подменено, чего нет — и откуда взять. Сверяет по хешам из описаний. |

## prints — принты

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `make_probes.py` | хост | Пять эталонов печати: сетка 20 см, линии, буквы, плашка, непрозрачный фон. Детерминирован. |
| `variants.py` | контейнер | Та же картинка, изменённая так, что хеш её не узнаёт: вдвое меньше, JPEG 70, обрезка, светлее, «из чата». |
