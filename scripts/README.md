# Скрипты

Разбор и замеры данных стенда — только отсюда (CLAUDE.md, запрет 10). Нет
нужного — пишется сюда, в раздел по предмету, и строкой в эту опись.

Где запускается — в шапке каждого скрипта. Коротко: **хост** — одна
стандартная библиотека (плюс PyYAML), `py scripts/<раздел>/<скрипт>.py` из
корня репозитория; **контейнер** — нужны PIL, numpy или код сервиса,
`docker compose -f infra/compose.yaml exec -T api python -m scripts.<раздел>.<скрипт>`.
Том файлов в контейнере только на чтение: что надо записать, уходит в stdout.

## stand — том стенда

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `fetch_models.py` | хост | Нейросети и словарь по описи `fixtures/models.json`: закреплённая ревизия, sha256, докачка оборванного. До подъёма стенда, одной стандартной библиотекой. |
| `measure_model_memory.py` | контейнер | Сколько памяти каждая модель занимает в работе, а не на диске, — против бюджета 2 ГБ (US-0624). Числа переносятся в `models.json`. |
| `age_library.py` | контейнер | Состарить библиотеку стенда: разметка как до плана 087 — проверить переразметку (US-0629). Только стенд. |
| `verify_volume.py` | хост | Что в томе на месте, что подменено, чего нет — и откуда взять. Сверяет по хешам из описаний. |

## prints — принты

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `make_probes.py` | хост | Пять эталонов печати: сетка 20 см, линии, буквы, плашка, непрозрачный фон. Детерминирован. |
| `variants.py` | контейнер | Та же картинка, изменённая так, что хеш её не узнаёт: вдвое меньше, JPEG 70, обрезка, светлее, «из чата». |
| `alpha.py` | хост | Вырезан ли принт или это сцена с прозрачной рамкой. |
| `commons.py` | хост | Поиск и скачивание принтов с Wikimedia Commons с правом и автором (только PNG и SVG — фото в JPEG не берёт); векторные — сразу в PNG с прозрачностью, 16 бит сводятся к 8. |
| `contact_sheet.py` | контейнер | Лист миниатюр набора на шахматке — ожидания пишутся по картинкам, а не по именам файлов. |

## garment — изделие

Кадрам и исходнику. Числа в `infra/stand/fixtures/<код>.yaml` сняты этими
скриптами; расхождение с описанием они называют сами.

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `silhouette.py` | хост | Границы силуэта, профиль ширины, место плеч; сетка поверх кадра для чтения координат глазом. |
| `torso.py` | хост | Ширина торса с переда и спины, глубина с бока, низ подола — раздел `torso`. |
| `frame_colour.py` | хост | Обесцвечен ли кадр и гладок ли — годится ли он в карту освещения (решение 0001). |
| `bw_source.py` | хост + zstd | Что внутри исходника VStitcher и как достать файл. zstd: Python 3.14 или `pip install zstandard`. |
| `avatar_scale.py` | хост + zstd | В каких единицах сцена модели — по габариту аватаров против роста в их имени. |
| `geo_mesh_search_failed.py` | хост + zstd | **Не дал результата.** Поиск меша изделия в снимке симуляции — лежит, чтобы не пробовать в третий раз. |

Боковой шов скриптом не мерится: угол 90° принят решением 24.09.2026
(`torso.side_seam_deg`), настоящий берётся из лекала.

## embeddings — векторы, теги, поиск

Все — в контейнере. Ожидания записаны в `prints.yaml` до замеров; скрипт
сверяет с записанным и не считает молча на неполном наборе.

| Скрипт | На какой вопрос отвечает |
|---|---|
| `pairs.py` | Похожесть всех пар набора и три уровня: тот же объект, та же категория, чужое (US-0431). |
| `same_picture.py` | Узнаётся ли та же картинка после уменьшения, JPEG, обрезки, осветления; порог 0.91 (US-0431). |
| `measure_names.py` | Различает ли модель названия машин (US-0479). |
| `measure_tag_benchmark.py` | Автотеги по видам картинок — аниме, иллюстрация, плоская, надпись, фото — против `tag_benchmark.yaml` (US-0623). Неполный набор или вида меньше восьми — отказ. |
| `measure_router.py` | Различает ли CLIP вид картинки без обучения и при каком зазоре картинка идёт в две модели (US-0625). |
| `measure_anime_candidates.py` | Аниме-разметчики WD-tagger v3 на аниме эталона: попало, лишнее, скорость, память (US-0626). |
| `encoders.py` | Не замер — кандидаты общей модели (CLIP, SigLIP 2) для замера ниже. |
| `measure_general_candidates.py` | Общая модель: теги по видам, сцена, узнавание дублей, память — CLIP против SigLIP 2 (US-0627). |
| `measure_tag_search.py` | Поиск: порядок по картинке против порядка по тегам через текстовую модель смысла (US-0628). |
| `measure_search_rule.py` | Выдача так, как её отдаёт сервис — с порогами, точным тегом и проверенной добавкой по смыслу тега (US-0628). |
| `measure_words.py` | Двадцать тегов по весам из словаря языка против записанных ожиданий (US-0482). Без надписей из хранилища стенда — отказ, `--partial` считает без них. |
| `probe_query_ranking.py` | Находит ли слово запроса нужные картинки среди всех (к US-0480). Надписи — как выше. |
| `search_rule.py` | По какому правилу поиск словом говорит «нашлось» и «ничего»: место ожидаемой картинки, разделимость, куски картинки (US-0480). |
| `probe_words_centering.py` | Помогает ли центрирование против вездесущих слов (опыт US-0482, не помогло). |

(`file`, `write` — как пишут в замечании). Набор владельца ложится рядом.

| Скрипт | Где | На какой вопрос отвечает |
|---|---|---|
| `synth_phrases.py` | хост Windows | Предварительный набор фраз дела синтезатором (голос Irina), пока нет записанного владельцем. Число по нему — предварительное. |
| `measure_wer.py` | контейнер | Доля слов с ошибкой у расшифровки на наборе и сколько раз узнаны слова дела («Об. 268», «пантон», «кокетка»). |
