## Разрешения и окружение

Владелец явно ответил: **«Проверять изменения только локально»**. Не создавать
демонстрационные копии на production, не менять его карточки/статусы/людей
ради тестов. Разрешение не переспрашивать. В плане метод демонстрации US-0885
уточнён; локальную проверку не выдавать за действие на production.

Личный MCP-ключ допустим только на машине владельца. Никаких ключей в этой
ветке/заметке; production использует отдельные служебные ключи.

Для проверки использовались только локальный Postgres и отдельный MinIO
`reference-review-minio` на tmpfs, API `reference-review-api` (5185), frontend
`reference-review-web` (5184). Старый MinIO-том не запускается из-за отказа
переименования `.minio.sys/tmp`; он не изменялся и не очищался. Не выполнять
рекурсивный chown/удаление его данных наугад. Подготовить отдельный tmpfs
MinIO снова, направить API на него и на БД с суффиксом `_test`.

При остановке свои тестовые контейнеры останавливаются; tmpfs S3 исчезнет.
Исходники/кадры и обычная локальная БД не удаляются. Долгие операции запускать
в фоне, не оставлять пользователя без содержательного сообщения.
