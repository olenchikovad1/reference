# Решения

Что выбрано, почему, **что рассмотрено и не поддерживается — с основанием**, и
когда решено.

Ценность записи — в отклонённых вариантах. Без них через полгода решение
выглядит произвольным, и его переигрывают заново, часто приходя к тому, что уже
пробовали и отбросили.

Дата обязательна: решение принимается в обстоятельствах, а обстоятельства
меняются.
