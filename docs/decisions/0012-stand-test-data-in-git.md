# 0012. Тестовые данные стенда — в git; вне его только исходники моделей и нейросети

**Дата:** 25.09.2026
**Пересматривает:** [0002](0002-two-storage-classes.md) в части «том стенда целиком вне git»
**Касается:** `.gitignore`, `infra/stand/files/`, `scripts/stand/verify_volume.py`

## Задача

Стенд переехал с офисной машины на домашнюю и оказался пустым. Кадры изделия,
принты владельца и эталоны лежали в `infra/stand/files/`, а она целиком стояла
в `.gitignore` по решению 0002. О том, что данных нет, узнали по упавшим
проверкам. Вернуть их удалось только потому, что владелец нашёл у себя те же
файлы, а генератор эталонов — потому, что он остался в транскрипте сессии.

## Решено

**Папка данных стенда в git.** Туда входят кадры состояний, принты набора и
набора для настройки, эталоны и производные варианты. Всё, на чём стоят
проверки, описания изделий и замеры, приходит с клоном.

**Вне git только два вида файлов:**
- исходники моделей из VStitcher (`products/*/source/`, сотни мегабайт на
  модель). Стенду они не нужны: код читает только путь из описания изделия;
- нейросети и словарь (`models/`, `dictionaries/`, около 290 МБ). Их качает
  `scripts/stand/fetch_models.py`, размеры сверяются.

## Почему

**Данные стенда — часть проверок, а не склад.** Хеши кадров записаны в описании
изделия, ожидания узнавания — в описании набора, тесты открывают принты по
именам. Код, который ссылается на отсутствующие в репозитории файлы, на чистом
клоне не проверяется ничем.

**Вес терпимый и названный.** Кадры около 0.5 МБ, принты владельца около 20 МБ,
набор для настройки около 50 МБ одним разом. Владелец согласен на 2–3 МБ за
картинку (25.09.2026).

**Довод решения 0002 про исходники остаётся в силе.** Модель на 444 МБ в
истории репозитория — это склад. Моделей будут тысячи, и никакой проверке
исходник не нужен.

## Цена, названная явно

- **История растёт с каждым новым принтом.** Удалённый из набора файл остаётся
  в истории навсегда. Добавлять в набор стоит то, что нужно проверкам, а не
  всё, что попалось.
- **Двоичные файлы не сливаются.** Два человека, одновременно поправившие одну
  картинку, получат конфликт, который решается только выбором одной версии.
  Картинки набора правятся редко, и это приемлемо.

## Рассмотрено и отклонено

**Оставить папку вне git и держать инструкцию, откуда брать файлы.** Отклонено:
именно так и было, и инструкция не помогла. Источник — офисная машина или
«Загрузки» владельца, а это не адрес, по которому можно скачать.

**Git LFS.** Отклонено: нужен сервер LFS и его квота, а клон без установленного
LFS молча получает указатели вместо картинок. Это та же пустота, только хуже
заметная. При 20–70 МБ выигрыша нет. Пересмотреть, если набор перерастёт
несколько сотен мегабайт.

**Хранить набор в объектном хранилище стенда.** Отклонено: MinIO живёт в томе
докера конкретной машины. Именно так на офисной машине остались две надписи
для замеров тегов.
