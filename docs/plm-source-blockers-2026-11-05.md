## Решение и граница работы

- US-0887, 3 SP: готовое сохраняется; нужен ограниченный машинный путь
  от цветомодели к существующим пригодным изображениям. Обход всех релизов
  для каждой плитки и зеркало каталога не вводятся. Старый preview500 снят.
- US-9533, 8 SP: нужны реальные ракурсы, базовый размер и физические мерки
  нескольких типов с источником. Стендовая худи не заменяет другие изделия.
  До общего пути калибровки требуется достаточный контракт источника.
- US-0888, 5 SP: нужен владелец источника подтверждённого профиля/окна группы.
  Недели дропа и коэффициенты спроса не являются политикой скрытия.

Истории остаются непринятыми; runtime Reference не менялся. Повторный
опрос нужен после ответа/новой версии PLM, постоянное ожидание не запускается.
Локальный API отдельно получил ConnectError к прежнему read-only мосту.
Это состояние проверочного окружения, а не отказ production: реальные
три GET успешны. Поднимать новый стек для доказательства тех же полей не нужно.
