# Загрузка витрины и текстов — 02.11.2026

На первом браузерном проходе видимые миниатюры появились через 23,6 с.
Повторные проходы того же production занимали 2,9–3,3 с, но каждый начинал
103 запроса миниатюр и загружал ресурсы скрытого редактора: палитру PLM,
принты и три кадра изделия. Быстрый повтор не опровергает исходную задержку.

Read-only профиль внутри production API: 149 карточек — 0,311 с / 32 SQL;
26 текстов — 0,104 с / 33 SQL. Ненужные ORM-загрузки существуют, но в этом
воспроизведении основное ожидание происходит после ответа списка.

Изменение: браузер лениво загружает миниатюры, показывает загрузку и ошибку
вместо пустой картинки. Редактор впервые создаётся при открытии его адреса,
после закрытия сохраняет экземпляр и черновик. Предварительная загрузка всех
кадров убрана; список «мой ход» запрашивается при включении фильтра.
Списки референсов и текстов используются из кэша 30 с; существующие
инвалидации после изменений продолжают обновлять их сразу.

Локальная production-сборка с настоящим API production: 45 исходных запросов
миниатюр, без ресурсов скрытого редактора; видимые изображения — 2,7–3,9 с,
тексты — 0,2–0,6 с. Прокрутка догружает дальние изображения, возврат к витрине
не перечитывает список. Отдельно проверяется редактор по прямому адресу и
закрытие клавишей Escape без уничтожения экземпляра.

Автоматизация: `scripts/stand/profile_browser.cjs`, параметры описаны в
`scripts/README.md`. Новый контекст Chrome исключает браузерный кэш.
В этих замерах только оболочка платформы `/me` заменена локальной фикстурой:
MCP-ключ не является браузерной сессией. Данные Reference и изображения
читаются через настоящий production-шлюз с настоящей проверкой доступа.
Этот сценарий не доказывает работу браузерного входа платформы.

Ключ берётся из локального файла доступа и не отправляется в окружение
приложения. Сохранённый сетевой отчёт содержит пути, размеры и длительности,
без заголовков. Профиль SQL: `scripts/stand/profile_lists.py`, без записей
в базу и без запуска фоновых задач приложения.

Откат — предыдущий выпуск штатной установкой; схема и данные не меняются.
